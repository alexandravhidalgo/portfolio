# Alexandra Hidalgo — Portfolio

Static portfolio site. No build step — plain HTML, CSS, and JS.

- `index.html` — the site
- `industry.css` — design-system tokens
- `app.js` — scroll-reveal, count-up, and hover-lift interactions

## Local preview

```bash
python3 -m http.server 8099
```

Then open http://localhost:8099

## Hosting

Deployed via GitHub Pages from the `main` branch (root). `.nojekyll` disables Jekyll processing.
